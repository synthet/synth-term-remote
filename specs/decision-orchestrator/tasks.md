# Headless decision orchestrator: tasks

Spec: [spec.md](spec.md). Items: [items/](items/). Baseline: `main` 58e796c.

Each task is one PR. Task IDs are `<item>.<n>`; a dependency on a task ID means that task only. ACs are item ACs `<item>/AC-n` defined in each item file. "Covered by" rows point at existing tickets and create no new ticket. Every task's Definition of Done: `cargo fmt --check`, `cargo clippy --all-targets -- -D warnings`, `cargo nextest run --no-fail-fast`. Tasks whose owner role says "security" also need a review with `.claude/skills/threat-modeling-agentic-tools`.
